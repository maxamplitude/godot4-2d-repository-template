# godot4-2d-repository-template

A template for any 2D game - barebones


## Instructions

This repository is a template for your 2D game.  To use:

* Edit the docs/game-design-document.md
* Edit project.godot to rename your project accordingly
* Commit your project to a new github repo
* Ensure ci.yml tests run as expected
* Replace this README.md with one appropriate for your game
